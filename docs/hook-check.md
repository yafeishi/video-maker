# 钩子前 3 秒检查（成片前必跑）

`node tools/check-hook.mjs films/<片名> [--secs 3]` · PASS 退出 0，FAIL 退出 1。`tools/make.sh` 与 `tools/build-if-approved.mjs` 自动跑；确认要保留开场可 `HOOK_SKIP=1 sh tools/make.sh …`，交付时说明。

读 `lines.json`（有 `events.json` 用真实时间，否则按约 4.5 字/秒估算）取前 ~3 秒台词；可选读 `TREATMENT.md` 开头看有无开场画面主体（没有只 WARN）。

与自媒体运营人审 P0「前 3 秒」对齐的**四大死法**（2026-10-27 运营确认稿）：

| # | 死法 | 判定（启发式） | 改法方向 |
|---|---|---|---|
| 1 | 慢开场 | 首句是招呼、自我介绍或「本期/这期」铺垫，且没有问题、反差、冲突或开场画面指令 | 删招呼，直接抛具体问题、反差或画面指令（用片里真实内容） |
| 2 | 纯字墙 | 首句有效字 >28，且无问句、反差词、具体物件或「你」；**裸年代/序号数字不算钩子** | 首句砍到 ≤20 字，留问句、反差、物件或「你」；其余挪到第 2 句 |
| 3 | 抽象空话 | 开场含空话/AI腔（在当今、随着…发展、赋能、底层逻辑、闭环、众所周知等） | 换成观众会遇到的具体场景或痛点 |
| 4 | 铺垫倒置 | 前 3 秒只在铺年代、背景或原因，核心问题、反差或片名承诺未出现 | 把核心问题、反差或片名承诺提到前 3 秒；年代背景往后放 |

## 范围说明

- 本工具**只做台词启发式**；画面主体仍以 WARN / **人看成片**为准。
- 启发式会漏判/误判。运营审片仍以人审 P0 为准。
- 改法只给方向，**不编细节**；改完的台词照旧过 humanizer。

## 反例

`us-territory-rise`：工具旧版曾 PASS，人审硬伤是前 3 秒事实铺垫，核心问题约在 28 秒才出现（应对齐「铺垫倒置」）。
