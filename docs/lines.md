# lines.json 写法（数据驱动模板）

`qa`、`review` 两个模板的整部片都由 `lines.json` 生成，**不用写代码**。做片只需要三步：

1. `sh tools/new-film.sh review 片名`（或 `qa`）建片；
2. 照下面的例子改 `films/片名/lines.json`；
3. `sh tools/make.sh films/片名`：检查 → 出片 → 配音检查 → 联系表，最后告诉你还要改什么。

不要改 `film.js` 和 `audio.py`。检查器（`node tools/check-lines.mjs films/片名`）报的每一条都写了怎么改。

## 1. 基本规则

```json
{
  "voice": "zh-CN-YunyangNeural",
  "lines": [
    { "id": "t1", "shot": "title", "title": "走出地球", "text": "从一颗卫星到登上火星，人类只用了六十多年。" },
    { "id": "h1", "shot": "timeline", "items": [ ... ], "text": "第一句。" },
    { "id": "h2", "text": "接着上一个镜头说的第二句，画面不切。" }
  ]
}
```

- **每句台词一个对象**：`id`（英文编号，不重复）和 `text`（要说的话，也是字幕）。
- **写了 `"shot"` 就开一个新镜头**，镜头的内容字段写在这一句里。不写 `shot` 的句子接在上一个镜头里继续说。
- **一句台词不超过 34 个字**（字幕一行），说不完就拆成两句。
- 画面上的条目会在配音**说到它的时候**出现：给条目写 `"hit"`（台词里的一个词，要一字不差），就对齐到那个词；不写就按台词均匀分布。
- 配音读错的字：加 `"say"` 写读音（只影响配音，不影响字幕）。配音检查只是写法不同（数字、同音字）：加 `"asr"` 写听写结果。
- 换配色：顶层加 `"style": { "acc": "#7cc4ff" }`（可改 `bg` `ink` `dim` `line` `acc` `warm`）。
- 结尾互动：顶层 `"cta"` 块 + `cta1`、`cta2` 两句台词，见 §3。

## 2. 镜头类型

每种镜头都有最短时长，配音更长时会自动撑开。字数上限是建议值：超了字会自动缩小，但读起来吃力。

### title 片名卡

```json
{ "id": "t1", "shot": "title", "kicker": "1957 — 2021", "title": "走出地球", "sub": "人类探索太阳系的六十多年",
  "text": "从一颗卫星到登上火星，人类只用了六十多年。" }
```
`title` 必填，≤ 10 字；`kicker` 上方小字；`sub` 下方副标题。片子的第一个镜头用 `title` 或 `question`。

### question 问题

```json
{ "id": "q1", "shot": "question", "text": "天空为什么是蓝色的？" }
```
画面默认显示台词本身（去掉问号）。问句超过 12 个字时写一个更短的 `"big"`。

### answer 一句话答案

```json
{ "id": "a1", "shot": "answer", "big": "散射", "tag": "瑞利散射", "hit": "散射", "text": "因为阳光里的蓝光，最容易被空气散射。" }
```
`big` 必填，≤ 6 字（关键词或数字）；说到 `hit` 时砸下来；`unit` 单位；`tag` 下方标签。紧跟在 `question` 后面。

### stat 大数字

```json
{ "id": "s1", "shot": "stat", "value": "8", "unit": "颗行星", "label": "2006 年起，冥王星被划为矮行星", "hit": "八颗",
  "text": "2006 年起，太阳系的行星定为八颗，冥王星成了矮行星。" }
```
`value` 必填，只写数字（`"40"`、`"5.9"`、`"1,200"`），单位放 `unit`。数字从 0 跳到 `value`，说到 `hit` 时定格。

### point 要点

```json
{ "id": "p1", "shot": "point", "kicker": "波长", "title": "波长越短，散射越强", "items": ["蓝光 ≈ 450 nm", "红光 ≈ 700 nm", "蓝光散射约为红光的 5 倍多"],
  "text": "空气分子对波长短的光，散射得更厉害。" }
```
`title` 必填，≤ 12 字；`items` 0–3 条，每条 ≤ 16 字，最后一条是结论（强调色）。连续几个 `point` 会排成一组，左上角显示「01 / 04」。

### timeline 时间线

```json
{ "id": "h1", "shot": "timeline", "title": "走出地球的脚印",
  "items": [
    { "year": "1957", "label": "第一颗\n人造卫星", "hit": "人造卫星" },
    { "year": "1969", "label": "阿波罗11号\n登上月球", "hit": "登上月球" }
  ],
  "text": "1957 年，第一颗人造卫星上天。" }
```
`items` 2–8 条，按时间先后排；`year` ≤ 6 字；`label` 每行 ≤ 9 字，`\n` 换行。镜头跟着讲到的那一条走，讲完拉远看全貌。条目多就多写几句不带 `shot` 的台词接着讲。

### bars 柱状图

```json
{ "id": "b1", "shot": "bars", "title": "这些行星有多大", "unit": "直径 · 以地球为 1",
  "items": [ { "label": "水星", "value": "0.38" }, { "label": "木星", "value": "11.21", "hit": "木星" } ],
  "text": "木星的直径是地球的十一倍多。" }
```
`items` 2–8 条，`label` ≤ 6 字，`value` 只写数字（不能是负数）。最大的一条用强调色，想强调别的写 `"highlight": "地球"`。显示几位小数跟你写的一样（`"1.00"` 显示 1.00）。

### quote 引语

```json
{ "id": "q1", "shot": "quote", "quote": "这是个人的一小步，却是人类的一大步。", "by": "尼尔·阿姆斯特朗，1969",
  "text": "阿姆斯特朗踏上月球时说：这是个人的一小步，却是人类的一大步。" }
```
`quote` 必填，≤ 40 字。台词里要把引语原文完整念一遍，画面会跟着逐字亮起。只引用公开、简短的原话，并在 `CREDITS` 注明出处。

### recap 收束

```json
{ "id": "r1", "shot": "recap", "title": "下一站，更远", "sub": "卫星 · 月球 · 火星 · ……", "text": "六十多年，人类从一颗卫星走到了火星，下一站会更远。" }
```
`title` 必填，≤ 10 字，用一句更短的话呼应开头。放在最后（结尾互动之前）。

## 3. 结尾互动

```json
"cta": {
  "question": "你最想去太阳系哪里",
  "options": [{ "label": "月球" }, { "label": "火星" }],
  "placeholder": "说说你想去的地方",
  "typed": "我想去……",
  "button": "评论",
  "footer": "评论区见"
},
...
{ "id": "cta1", "text": "如果能去太阳系任何一个地方，你最想去哪里？" },
{ "id": "cta2", "text": "在评论区告诉我们吧。" }
```
问题要具体、观众凭自己经历就能答；选项取自片子里讲过的东西（≤ 6 个，每个 ≤ 6 字）。规则见 `docs/directing.md` §3「结尾互动」。

## 4. 常用结构

| 题目 | 镜头顺序 | 模板 |
|---|---|---|
| 为什么 / 是什么 / 怎么会 | question → answer → point × 2–4 → recap → cta | `qa` |
| 回顾、历程、盘点 | title → timeline → quote 或 point → bars / stat → recap → cta | `review` |
| 一个数据说明一件事 | title → stat → point × 2–3 → recap → cta | `review` |
| 排行、对比 | title → bars → point × 2–3（逐个解释） → recap → cta | `review` |

两个模板用的是同一套镜头，镜头类型可以任意组合，模板只是给了不同的示例和开头。全片 45–90 秒，镜头 6–10 个。

## 5. 事实

片子里的年份、数字、名字都要能查到出处，写进 `CREDITS`。拿不准的数字不要放进 `stat` 和 `bars`，改成不带数字的 `point`。
