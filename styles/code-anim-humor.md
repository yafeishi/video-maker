# 代码动画·幽默快节奏（参考：video-stock 的 AI呆娃 / 提示词翻车秀 / 小狗打工记）

> 来源：2026-10-16 由 Cursor 云端 Agent 用代码逐帧绘制的动画（非工作台模板渲染）。工作台选此风格只记在简报里，并把本规格交给生成方（film.js 编写者/Agent）照做。

## 画幅与技术
- 1080×1920 竖屏，30fps，28–45 秒；代码绘制矢量卡通（canvas/SVG 逐帧）→ ffmpeg 合成，配自合成背景音乐（无版权素材）。
- 每条配封面 png（首屏标题帧）。

## 视觉
- 扁平 Q 版卡通：粗深色描边、圆润造型、腮红、大眼；暖色/粉彩背景（奶黄、蜜桃、浅蓝、夜景深紫）。
- 每个场景一个完整小场景（房间/店铺/街道），角色居中偏下，道具清楚可读。
- 顶部药丸标签标「第N关 / 打工1/3」等进度；UI 卡片（App 界面、清单、报错屏）作为笑点载体。
- 底部深色圆角字幕条，白/黄字，一句一条，短口语。

## 节奏与结构
- 0–3 秒钩子：大字拟声/标题（「哇——！」「小狗打工记」）+ 冲突画面。
- 3 关结构（3 个小场景），每关 3 拍：设定 → 期待 → 翻车（「失败×N」印章 / 红字划掉 / 「结果——」反转）。
- 每 3–5 秒一个镜头/字幕变化，节奏快，不拖。
- 结尾温情反转收尾（「辛苦啦小宝贝」「宝宝最爱的还是这个笨笨的爸爸」）+ 总结卡（如「今日带娃报告」）。

## 文案
- 生活化题材 + AI/打工等热点梗；自嘲、萌、反差；不说教。
- 字幕即台词，可无旁白；如需配音用活泼音色（晓伊）。

## 实测规格（来自 video-stock/puppy-jobs.mp4 抽帧，2026-10-16）
- 规格：1080x1920 / 30fps / 42s，BGM 全程无静音段（-35dB 检测无 silence），ai-dai-wa 45s 仅 11.1s、33.7s 两处短静音（段落切换）。
- 镜头：约每 1s 一个"状态变化"，但硬切少（scene>0.25 检测为 0）——靠同场景内道具/表情/字幕变化推进，场景切换用云朵/烟雾满屏遮罩转场。
- 结构：开场钩子（"小狗破产了？！"+放射条纹底+存钱罐）→ 标题 → 3 份工各 ~9s（干活→出事→失败印章 x1/x2/x3）→ 回家温情（夜窗、留饭便签）→ 互动问题卡（"如果小狗来你家打工…" + 3 选项按钮）。
- 场景必须满：每份工 ≥6 个道具（咖啡：黑板菜单、咖啡机、吊灯、木柜台竖纹、咖啡杯、贴纸；程序员：显示器代码滚动、便利贴、窗外云、耳机、眼镜；外卖：彩色楼群、云、马路虚线、电动车、外卖箱）。顶部左上小"打工1/3"徽章+职业名标签。
- 角色：比熊，毛团用 6–8 个"扇贝边"圆叠成蓬松轮廓（不是 5 个整圆）；描边深棕 ≈#4a3a35，约 7px@1080；毛色 #f5f1eb + 头顶浅灰阴影斑；眼睛黑圆+两颗高光，粗眉随情绪变化；鼻子带高光；腮红 #fdc4d0 椭圆半透明；粉色波点荷叶领 #feb1c4 + 蝴蝶结；薄荷围裙 #a4e5cd + 爱心；贝雷帽 #a87550 带小柄。
- 配色：暖粉/奶油墙竖条纹，柜台 #c68a58 带竖向木纹，黑板 #34504a。
- 字幕：底部居中圆角药丸，y≈1360–1485（高≈125），底色 #4d362b，1px 粉白描边+下投影，白色圆体手写字（类站酷快乐体）≈70px，省略号点状。每句 1.5–3s，与动作同拍。
- 笑点：重复三次失败+印章计数(x1→x2→x3)；"轻轻地…慢慢地…"后大爆炸烟雾；角色表情反差（自信眉→黑线→睡着）。
- 动效：呼吸上下浮动、印章大→小回弹+轻旋转、烟雾云扩张盖屏、心形/Z 字飘起。
