# 暗色发布会 · Dark Keynote

产品发布会、技术概念讲解、开源项目介绍、年度数据回顾。黑底、大字、一种强调色，靠排版、光和节奏说话。

示例片：《一帧一行》（`film.js`，约 40 秒），讲的就是这个工作台本身。分镜见 [`TREATMENT.md`](TREATMENT.md)。

## 1. 画面

- **底色**：接近黑的蓝黑 `#07090d`，四角压暗（径向暗角），远景一层稀疏点阵（视差 0.45，让 2D 相机移动时有纵深）。
- **颜色只有三层**：文字 `#e9edf3`、次要信息 `#667085`、线框 `#2a3345`。**强调色只用一种**：薄荷青 `#46f0c4`。整片最多再给一个暖色 `#ffb14a`，留给情感转折（示例片里留给结尾的「你的故事」）。
- **字体**：中文 Noto Sans SC（标题 700–900，正文 400），代码和数字 JetBrains Mono。标题字号 170–420 px，一屏只放一个主角。
- **发光**：只给强调色和主角加 `shadowBlur`，其他元素不发光。发光越少越贵气。
- **颗粒**：很轻（`GRAIN=1`）。深色渐变上颗粒太重会显脏。

## 2. 故事

- 一个概念、一个转折、一个回响。开头 3 秒内出现钩子（示例：黑屏里一个光标开始打字）。
- **本风格的原生手法**：抽象概念变成可见的图形。一个字母长成一条时间轴，一个画框复制成一整张联系表，五条轨道收拢成一条光线，光线再变成片名下的横线。把最强的一次变形放在情绪顶点。
- 结尾呼应开头：同一个动作，换了内容（开头打 `render(t)`，结尾打 `render(你的故事)`）。

## 3. 节奏

- 每分钟 100 拍，1 拍 = 0.6 s。镜头时长按拍写，配音更长时自动撑开，并对齐到 2 拍（`layout(..., { quant: 2 * BEAT })`）。剪辑点因此都落在音乐网格上。
- 至少一次「呼吸」：示例片第 4 镜开头两拍几乎静默，只剩一个脉动的小点，然后「24」砸下来。
- 片名卡至少停 4 秒。

## 4. 相机

- 2D 相机：`{ x, y, z, r }`，所有元素都经过同一个 `cam()`。
- 每个镜头一种运动：推（打字）、拉 + 横移（时间轴）、慢推 + 轻微荷兰角（联系表）、静止 + 冲击抖动（24）、跟拍播放头（轨道）、汇聚后推近（片名）、推向光标（结尾）。
- 镜头之间用「同一个元素」衔接，而不是淡入淡出：字母 `t` 的位置、播放头上方的画框、收缩成光标的横线。

## 5. 版式

- 画面中心是主角，字幕固定在底部中间（46 px，白字，黑色柔光描边），主角不放在下方 1/5。
- 代码类文字左对齐、逐字打出（每字 0.1 s，配按键声），光标 60% 占空比闪烁。
- 数字用 JetBrains Mono，标签全大写、字距拉开（`letterSpacing` 12–18 px）。

## 6. 声音

- **配乐**：程序化电子乐。和弦垫（锯齿波三重失谐 + 低通）打底，第二镜进脉冲贝斯和踩镲，第三镜加拨弦琶音和底鼓，第五镜全编制（四拍底鼓、二四拍拍手），片名前鼓全部撤掉只剩上扬音效，片名落下时一个低频冲击 + 大和弦 + 五个钟琴音（对应五个字）。
- **拟音**：按键（每个字符）、滴答（播放头扫过刻度）、快门（联系表出格）、嗖（转场）、低频冲击（大数字）、上扬 + 轰（片名）、铃（高亮）。都在 `window.EV` 里写好时间，`audio.py` 按时间放。
- **混音**：配音压缩后比音乐高约 10 dB（`audio.py` 按配音区间的 RMS 自动算音乐增益），配音下音乐闪避 −7 dB，总线 38 Hz 高通，最后 −14 LUFS。

## 7. 适合的题材

发布会开场、功能介绍、开源项目 README 视频、技术原理 60 秒讲解、年终数据、团队周年。
不适合：温情叙事、儿童内容、需要角色表演的故事（换别的模板或写新风格）。

## 8. 踩过的坑

- **逐字位置要在初始化时量好。** 绘制过程中 `g.font` 会被别的函数改掉，临时再量会用错字体，结尾那行字距就散了。
- **`letterSpacing` 是画布状态的一部分**，改完要还原或放进 `save()/restore()`。
- **配音压在冲击音效后面会听不清**：「一秒」被转写成「疫苗」，把台词挪到冲击尾巴之后 0.4 s 解决。成片混音要跑一次 `core/tts/asr_mix.py`。
- **贝斯基频太重**：频段报告里 20–60 Hz 最响时，把 `bass(body=)` 调小，靠 2、3 次谐波出声。

## 9. 示例片怎么做的

- `film.js`：`SHOTS` 定义 7 个镜头的最短拍数和台词；`layout()` 读 `voices/dur.json` 排时间线；每个镜头一个绘制函数 `shotXxx(lt, s)`；`EV` 里写所有音效和配音事件。
- `audio.py`：读 `events.json`，逐拍判断当前镜头，决定这一拍用哪些乐器；再放拟音和配音，做闪避和电平平衡。
- `build.sh`：一键出片，步骤见 `core/build.sh`。
