# 回顾盘点 · Review

历程回顾、年度盘点、数据对比、排行。结构一般是 **片名 → 时间线 → 引语或要点 → 数据（柱状图 / 大数字）→ 收束 → 结尾互动**，画面沿用暗色发布会（`keynote`）的黑底、大字、一种强调色。

示例片：《走出地球》（约 68 秒），人类探索太阳系的六十多年。分镜见 [`TREATMENT.md`](TREATMENT.md)。

和 `qa` 一样，整部片由 `lines.json` 生成，**换题目只改 lines.json**。镜头类型和字段见 [`docs/lines.md`](../../docs/lines.md)，两个模板用的是同一套镜头（`core/deck.js`）。

## 1. 画面

- 底色、字体同 keynote。示例片把强调色换成天蓝 `#7cc4ff`（`"style": { "acc": "#7cc4ff" }`），题目有自己的颜色时就换，整片只用一种。
- 暖色 `#ffb14a` 只给引号和问号。
- 片名：逐字升起，下方一条强调色横线拉开。
- 时间线：条目横向排开，镜头跟着讲到的那一条走，当前一条用强调色；讲完拉远看全貌。
- 柱状图：条目依次长出，数字跟着涨，最大的一条（或 `highlight`）用强调色。
- 大数字：从 0 跳到目标值，说到 `hit` 时定格变色、镜头一震。
- 引语：跟着配音逐字亮起。

## 2. 故事

- 回顾片最容易变成流水账。先想清楚**一句话**（示例：「从一颗卫星到登上火星，只用了六十多年」），片名镜头就说这句话，收束镜头换一种说法再说一遍。
- 时间线只挑 5–7 个节点，每个节点一句话讲得清。
- 数据镜头要回答一个观众会好奇的问题（「这些行星有多大」），不要为了有图而放图。
- 结尾互动问观众自己的选择或经历（「你最想去哪里」），选项取自片中出现过的东西。

## 3. 声音

配乐按镜头自动编配（`core/audio/deck.py`）：片名和引语安静，时间线和柱状图有律动且越往后越满，大数字先静后砸，收束上扬后爆响。

## 4. 适合的题材

历程、周年、年度回顾、行业盘点、排行榜、「一张图看懂」。
不适合：需要讲清原理的题目（用 `qa`），情绪叙事（用 keynote 或 blank）。

## 5. 踩过的坑

- **条目的 `hit` 要按顺序出现在台词里**，否则后面的条目会被推到最后才出来（检查器会报错）。
- **柱状图数值差太大**（0.38 和 11.21）时小的几条几乎看不见，这是真实比例，保留；需要看清小值时拆成两个镜头。
- **年份写成「1957 年」**：配音读「一九五七年」，配音检查按逐位读法比对，不会误报。
